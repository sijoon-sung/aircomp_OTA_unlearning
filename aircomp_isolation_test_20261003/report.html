AirComp 간섭은 SISA 삭제 범위를 넓히는가?

실행 완료 · 합성 선형회귀 학습 · CPU · 새 프로토콜/보안 증명 없음

가설: 데이터 의존 shard 간 간섭이 있으면 삭제 영향이 다른 shard에도 전파되고, 정확한 선형 분리는 이를 제거한다.
독립변수: 직교/혼합/정확한 ZF/CSI 오차 ZF, 간섭 rho 0/.01/.1/.3, 잡음 std 0/.01.
종속변수: 미삭제 shard 변화, 부분-전체 재학습 오차, test MSE, 채널사용 수.
통제: 고정 shard·데이터·100 rounds·안전한 round20 checkpoint·대응 난수.

판정

H1 지지: rho>0 혼합 수신에서 360/360 삭제가 미삭제 shard 모델을 바꿨다. 잡음0 조건에도 발생하므로 receiver noise만의 현상이 아니다.
H2 지지: 직교 480/480, 정확한 ZF 480/480에서 해당 shard만 재학습한 결과가 동일 프로토콜 전체 reference와 허용 오차1e-9 이내 일치했다.
CSI 오차: std .02의 등가 채널 추정 오차를 준 ZF는 480/480에서 부분 replay 불일치. 오차 크기는 아래 수치로 보고하며 수치 불일치를 실용적 공격 성공으로 해석하지 않는다.

연구 판단: 독립성을 유지해야 한다는 기전은 확인했지만 기존 정확한 ZF도 이를 해결했다. 따라서 이 결과 자체는 새 언러닝 기여가 아니다. 후속 후보의 가치는 CSI 오차 아래에서 직교 방식과 기존 강건 수신보다 적은 비용으로 같은 삭제 품질을 확보하는지에 달려 있다. 이번에는 새로운 secure aggregation 방법을 만들거나 성능을 입증하지 않았다.

정의와 대조군

3 shards ×4 clients, 각64 samples, feature8+intercept. 각 shard의 마지막 client는 round20에 처음 도입한다. 그 직전 checkpoint에는 삭제 대상 영향이 없다. 각 요청은 그중 한 client만 삭제하는 독립 시나리오다. client가 처음부터 참여하는 일반 설정에서 중간 checkpoint로 정확히 삭제할 수 있다고 주장하지 않는다.

전체 reference: 같은 배정·수신기·잡음 실현·학습 스케줄로 모든 shard를 안전한 checkpoint부터 재실행.
부분 replay: 삭제 shard만 재실행. 다른 shard는 원래 최종 모델 유지·송신하지 않음.
sham: 데이터를 삭제하지 않고 같은 부분 replay를 수행. 혼합 수신에서는 다른 shard를 침묵시키는 것만으로 집계가 달라질 수 있어 이 대조군을 추가했다. 삭제 전파의 주 증거는 partial gap이 아니라 full reference의 미삭제 shard 변화다.

등가 MIMO: y=A g+n, A의 대각1·비대각rho. 3개 수신 차원이 필요하며 SISO 한 관측에서3개 합을 복원하지 않는다. 정확 ZF는 W=A⁻¹, 오차 ZF는 W=(A+.02E)⁻¹. shard 내부 집계·client precoding·peak power를 생략한 이상화된 모형이다. 동일한 원시 잡음을 결합하고 W를 고정했다. 수신 잡음은 ZF에서 Wn이므로 증폭 비용도 반영했다.
