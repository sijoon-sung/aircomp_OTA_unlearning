2026-10-03 정리 · 기존 실행 폴더 밖에 만든 요약본 · 이번 작업은 문서 정리이며 새 실험은 실행하지 않음.

아래 가설 문장은 기존 사전기록과 결과를 읽기 쉽게 재서술한 것입니다. 원래 사전기록을 소급 변경하지 않았습니다. E1~E7은 최근 상관·SNR·삭제 실험의 비교 항목이며, 서로 중복된 실행 결과를 사용합니다. 행 수를 독립 실험 횟수로 더하면 안 됩니다. 이전 초기 pilot 및 압축 실험 전체의 목록은 아닙니다.

가설독립변수종속변수고정할 조건상태
P1 · 삭제 후 비용까지 고려한 배정은 초기학습만 고려한 배정보다 삭제 비용이 낮다.초기학습 비용만 최적화 vs 초기학습+삭제 비용 최적화평균·상위 분위 삭제 RE, 초기학습 RE, 정확도동일 데이터 대표성 항·탐색 예산·K·seed·채널·삭제 시나리오미실행. 기존 joint에 삭제 항은 있었지만 이를 제거한 대조군이 없었음. 실행 전 임계값·규모 확정 필요.
P2 · OFDM에서 삭제 shard에 빈 부반송파를 재할당하면 삭제 지연이 줄어든다.shard별 고정 부반송파 vs 삭제 시 빈 부반송파 재할당삭제 지연(ms), 시간×주파수 자원, RF 에너지, 정확도총 대역폭·총 전력 한도·집계 오차 목표·고정 shard·부반송파별 채널미실행. 기존 SISO 직교 자원 모형은 OFDM 파형/부반송파 재할당 구현이 아님. 지연 감소를 총 통신량 감소로 해석하지 않음.
P3 · 실제 client의 데이터 분포와 무선 채널에 상관관계가 있다.조작 변수 없음(관측 연구)
설명변수: 데이터 분포 거리		채널 거리와의 상관계수·불확실성같은 client/장소/시간에 대응하는 실측 자료, 교란요인 처리미검증. 기존 실험의 합성 연결 계수로 현실 상관을 입증할 수 없음.

상세 조건 · 판정 기준 · 원자료

E1 — 합성 상관 실험

18조건 = 연결 3수준 × 배정 2종 × 3 seeds. FashionMNIST 12,000 train / 2,000 dev / 10,000 test, Dirichlet 0.5. 통신 실용 기준은 평균 삭제 RE 10% 이상 절감, 2/3 seeds 이상 개선, 평균 정확도 손실 2pp 이하, replay 전부 일치였다. 연결 계수 0/0.5/1에서 평균 삭제 RE 절감은 5.63/19.13/20.88%로 첫 수준 미달, 나머지 통과. 이는 E1의 정확도 가설 지지나 현실 상관 입증과 다르다.

비용: 정상 실행 696.28초(11.60분), GPU board 31.076Wh, local 호출 185,760회, 외부 유료 비용 0. 첫 실행은 scipy import 오류로 학습 전 종료 후 수정. 18/18 replay 일치.

사전기록 · 상세 결과 · 원자료 집계

E2~E7 — SNR·배정·프라이버시 및 clipping 진단

주 57조건 + 사후 진단 8조건, preflight 별도. 20 clients, FashionMNIST 12,000/2,000/10,000, CNN 38,282 parameters, Dirichlet 0.5, local SGD 2 steps × 64, lr 0.05. K=2/4/5를 조사했으며 주 확인 비교는 K=4·3 seeds. K=2/5는 한 seed 탐색이라 shard 수의 일반적 효과를 확정하지 않았다. K가 늘면 shard당 client 수는 줄고 고정 rounds의 총 무선 예산도 달라진다.

E2 원래 통과 기준: 공통 dev 70%에서 초기학습+삭제 RE 10% 이상 감소, 평균 test 손실 2pp 이하, 해당 SNR에서 3 seeds 중 2개 이상 달성. E3/E4는 별도 효과 크기 통과 문턱을 정하지 않은 대응 비교이므로 결과 방향을 기술했다. E6 진단 기준: 거의 무잡음 조건에서 dev/test가 각각 2pp 이상 개선. 0/20dB에서 C를 바꾸면 잡음 크기도 바뀌므로 순수 clipping 효과로 단정하지 않는다.

joint의 무선 점수에는 이미 초기학습과 가능한 단일 client 삭제 후 bottleneck이 모두 들어갔다. 데이터 대표성(JS)과 무선 점수를 0.5/0.5로 결합했다. 초기학습만 고려한 배정과 직접 비교하지 않았다.

완전 CSI·동기화·위상보상의 SISO 시뮬레이션. shard 간 직교 자원을 계산했으며 실제 OFDM, MIMO, 무선 trace는 검증하지 않았다. RE는 기존 실험의 등가 자원 환산 단위이며 실제 OFDM 처리량 측정치가 아니다. 정확도는 주로 삭제 후 test; dev는 목표 도달 지점 선택용. pp는 퍼센트포인트.

비용(주+진단+preflight 합계): 1,881.38초(31.36분), GPU board 약 83.98Wh, local 호출 475,212회, 외부 유료 비용 0. GPU 에너지는 RF 에너지가 아니다. 비용을 E2~E7 각 행에 중복 합산하지 않는다. 71개 삭제 비교의 284 checkpoints 일치; 공개 histogram/routing 자체의 삭제 보장은 별도다.
