# SISA–AirComp 아키텍처 실험 계획 (실행 전 고정)

작성 2026-10-06. 이 문서는 실행 전에 고정한 가설, 변수, 통제 조건, 판정 기준입니다. 결과를 본 뒤 기준을 바꾸지 않습니다.
기준을 바꿔야 할 사정이 생기면 이 문서를 고치지 않고 별도 문서로 남깁니다.

## 0. 연구 질문과 이 실험의 위치

질문은 "SISA 구조(독립 shard, 해당 shard 만 재학습)를 지키면서, 언러닝에 유리한 AirComp 아키텍처를 어떻게 짜는가"입니다.
AirComp 서버는 개별 데이터를 볼 수 없고, client 별로 아는 정보는 전력 제어에 쓰는 채널 정보뿐입니다. 그래서 아키텍처의 결정을 채널 정보만으로 내리는 것을 전제로 합니다.

검증할 구성 요소는 다음과 같습니다.

| 기호 | 구성 요소 | 실험 |
|---|---|---|
| - | 잡음 허용 한계 (모든 비용 계산의 기준) | G0 |
| ① | 삭제해도 다른 client 의 소속이 바뀌지 않는 채널 배정 규칙 | E1 |
| ② | 채널이 강한 client 를 먼저 참여시키는 단계적 참여 | E2 |
| ③ | 연속 삭제를 고려한 shard 크기와 합치기 규칙 | E3 |
| ④ | 삭제 중 남는 대역을 삭제 shard 에 몰아주기 | E4 |
| ⑤ | shard 사이 guard 대역과 주파수 배치 | E5 |

## 1. 공통 원칙

1. **한 실험에서는 하나만 바꿉니다.** 같은 seed 안에서는 데이터 분할, 채널 값, 초기 모델, (client, 라운드, local step) 별 minibatch, (shard, 라운드) 별 잡음 방향을 모든 조건이 똑같이 씁니다. 조건 사이 차이는 바꾼 변수에서만 나옵니다.
2. **비용과 정확도를 따로 잽니다.** AirComp scale 을 공개 clipping 한계 C 로 정하면, 채널 사용량·송신 에너지·지연은 학습과 상관없이 채널 값만으로 정해집니다. 그래서 비용은 CPU 에서 채널 표본 수백~1,000개로 계산하고, 정확도는 GPU 학습(seed 5개)으로 확인합니다.
3. **음성 대조와 반대 방향 대조를 둡니다.** 효과가 0 이어야 하는 조건에서 0 이 나오고, 반대 방향 조건에서 반대 결과가 나와야 원리가 확인된 것으로 봅니다.
4. **삭제 재학습은 원래 학습과 같은 라운드 수로 돌립니다.** 정확 언러닝과 같은 알고리즘이기 때문입니다.
5. 효과가 없다는 결과도 그대로 보고합니다.

## 2. 공통 설정

- 데이터: FashionMNIST. class 별 train 1,200 / dev 200 (합계 12,000 / 2,000), 공식 test 10,000. client 20명, Dirichlet(0.5), client 당 최소 60개. 분할 절차는 이전 실험(`research_20260929_pdf_ota_unlearning/core.py`)과 같습니다.
- 모델: 이전 실험과 같은 CNN(파라미터 38,282개). 모든 shard 가 같은 초기값을 씁니다.
- 학습: client 마다 local SGD 2 step (batch 64, lr 0.05, momentum 없음), update L2 clipping C=1, shard 안 client 균등 평균, 160 라운드. shard 모델은 공유하지 않고 마지막에 예측 확률만 평균합니다.
- 채널: 장기 진폭 10^(U[-20,0]/20), 라운드마다 U[0.85, 1.15] 를 곱합니다. 완전 CSI, 위상 보상, SISO. shard 사이는 직교 자원입니다(E5 제외). 이전 실험과 같은 seed 에서 같은 채널이 나옵니다(검증함).
- seed: GPU 학습은 71001~71005. CPU 해석의 채널 표본은 별도 키(`mc0`, `mc1`, …)를 씁니다.

## 3. 비용과 잡음의 식

채널 역보상 AirComp 에서 shard 의 활성 인원이 n, 가장 약한 채널이 h_min, 수신 잡음 분산이 σ², 심볼당 전력 상한이 P 일 때입니다.

- 1회 전송 집계 오차(잡음 벡터 제곱합): MSE₁ = C²σ² / (n² P h_min²)
- 같은 update 를 R 번 보내 평균하면 MSE = MSE₁ / R 입니다.
- 송신 에너지(공개 한계 C 기준 상한): E = C² D σ² Σᵢ hᵢ⁻² / (n² · MSE_달성). 같은 집계 오차를 얻는 데 드는 에너지는 반복으로 얻든 전력으로 얻든 같습니다.
- 전송 규칙(모드):
  - `R1`: 전력 상한으로 1회 전송
  - `fixed_mse`: MSE ≤ eps 가 될 때까지 반복
  - `min_energy`: MSE₁ ≤ eps 이면 전력을 낮춰 MSE = eps 로 맞추고(R=1), 아니면 fixed_mse 와 같음
- 시간: 기본 블록에서 심볼 1개를 보내는 시간이 1 입니다. 대역이 b 배면 같은 심볼 수를 1/b 시간에 보냅니다. 디지털 downlink 는 파라미터당 32 bit, 심볼당 2 bit 로 환산합니다.

**수식에서 나오는 예측.** shard 크기가 같고 잡음에 여유가 있으면(min_energy, R=1), 전체 에너지는 (1/n²)·Σ 모든 client hᵢ⁻² 에 비례합니다. 이 값은 배정 방식과 상관이 없습니다. E1 의 비용 표에서 확인합니다.

## 4. 실험별 계획

### G0 — 잡음 허용 한계 eps*

- 가설: 집계 오차가 어느 수준까지는 정확도가 떨어지지 않습니다. 그 한계 eps* 가 이전 실험의 목표 1e-4 보다 훨씬 클 수 있습니다.
- 독립변수: 라운드마다 집계 update 에 더하는 잡음의 집계 오차 eps ∈ {0, 1, 3, 10, 30, 100, 300, 1000, 3000, 10000}. 잡음 방향은 같고 크기만 다릅니다.
- 통제: 무작위 배정 4 shard × 5명, 데이터, 초기값, minibatch, 라운드 수.
- 종속변수: 초기 학습 앙상블 test 정확도, 삭제 4건(shard 마다 첫 client)의 앙상블 정확도 평균, 2명짜리 작은 shard 단독 정확도.
- 판정: 잡음 0 대비 하락이 **모든 seed 에서** 초기 학습·삭제 모두 1pp 이하인 최대 eps 를 eps* 로 둡니다. 낮은 단계부터 연속으로 통과한 것만 인정합니다. 평균 기준 한계와 2명 shard 기준 한계도 함께 보고합니다.
- 이후 실험에 넘기는 값: eps* (모든 단계 통과면 최대값, 하나도 통과 못 하면 가장 작은 단계의 1/10).
- 해석 규칙: 현실적인 최악 조건(0dB, n=1, h_min=0.1, MSE₁=100)에서도 반복이 필요 없으면, 채널 사용량은 어떤 조건에서도 같게 나옵니다. 그 경우 E2~E4 의 비용 판정은 에너지와 지연으로만 합니다(자동 반영).

### E1 — ① 삭제해도 바뀌지 않는 배정 규칙

- 가설:
  - H1a: 각 client 의 소속이 자기 채널로만 정해지는 규칙(채널 고정 구간)과 ID 해시는 삭제 후에도 다른 client 의 소속을 바꾸지 않습니다. 순위 기반 규칙과 무작위 순열 방식은 바꿉니다.
  - H1b: 소속이 바뀌는 규칙에서는 "해당 shard 만 재학습(SISA)"과 "규칙을 포함해 처음부터 학습(전체 알고리즘)"의 예측 차이가 학습 난수 변동보다 큽니다.
  - H1c: 채널 고정 구간 규칙의 정확도 손실은 채널 순위 자르기 대비 1pp 이하입니다.
- 독립변수: 배정 규칙 {무작위 순열 후 자르기, 채널 순위 자르기, 채널 순위 돌려 담기, 채널 고정 구간(-15/-10/-5 dB), ID 해시}. K=4.
- 측정:
  - (a) CPU 전수 계산: 채널 1,000가지 × 20명 삭제에서, 남은 19명에 같은 규칙을 다시 적용했을 때 소속이 바뀐 client 수
  - (b) GPU: seed 5개 × 규칙 5개 × 삭제 3건(가장 약한 채널, 중간, 가장 강한 채널). SISA 결과, 전체 알고리즘 reference, 같은 reference 를 다른 난수 tape 로 학습한 결과를 비교합니다. 명목 20dB, 1회 전송.
  - (c) 규칙별 초기 학습 정확도, 그리고 해석식 비용(채널 200가지)
- 판정: H1a 는 (a) 의 비율이 stable 규칙에서 정확히 0 이고 나머지에서 0 보다 클 때. H1b 는 SISA-reference 불일치가 난수 기준보다 큰 경우가 80% 이상일 때. H1c 는 평균 정확도 차이 1pp 이하일 때.

### E2 — ② 채널 순서 참여 시점

- 가설:
  - H2a: 참여 일정이 같을 때, 강한 채널을 먼저 넣으면 무작위 순서보다 초기 학습 비용 증가가 작고 기대 삭제 비용도 작습니다. 약한 채널을 먼저 넣으면 반대입니다.
  - H2b: 강한 채널 먼저의 정확도 손실은 무작위 순서 대비 평균 1pp, seed 별 2pp 이하입니다.
- 독립변수: 참여 순서 {전원 동시(기준선), 무작위, 강한 채널 먼저, 약한 채널 먼저(반대 대조), 자기 채널 구간으로 시점 결정(① 원리 적용판)}. 일정은 shard 안 순위대로 [0, 0, s, 2s, 3s] 라운드, s=20 (민감도 s=40).
- 추가 대조: 배정 {무작위, 채널 순위 자르기} × 순서 상호작용.
- 통제: 배정, 데이터, 채널, 160 라운드. 삭제는 그 client 가 들어오기 직전 checkpoint 에서 해당 shard 만 다시 학습합니다.
- 측정:
  - CPU: 채널 1,000가지 × 20명 삭제. 초기 학습 비용, 기대 삭제 비용(평균)과 최악 비용. 송신 에너지, UL 사용량, 전체 자원. 조건은 min_energy / fixed_mse(eps*) / fixed_mse(1e-4) / R1 × 0·10·20dB.
  - GPU: seed 5개 × 배정 2 × 순서 5 × 잡음 {0.01, 1} (1회 전송). 초기 학습과 20명 삭제 각각의 앙상블 정확도.
  - 일치 확인: 가장 먼저 / 가장 늦게 들어온 client 의 단계적 삭제 replay 와 처음부터 제외하고 학습한 reference 의 파라미터 차이.
- 판정: H2a 는 주 조건(무작위 배정, s=20, min_energy 의 에너지. G0 에서 반복이 필요하다고 나오면 eps* 기준 fixed_mse 의 UL 사용량도 포함)의 모든 SNR 에서, 다음 네 관계가 채널 표본 80% 이상에서 성립할 때 지지합니다.
  - P(강한 순 초기 증가 < 무작위)
  - P(강한 순 삭제 < 무작위)
  - P(약한 순 초기 증가 > 무작위)
  - P(약한 순 삭제 > 무작위)

  전력 상한으로 그냥 보내는 R1 의 에너지는 잡음이 조건마다 달라 비용 비교 대상이 아닙니다(보고만 함).

### E3 — ③ 연속 삭제와 shard 크기

- 가설 H3: 연속 삭제 수 L 에 따라, 통신·계산 종합 점수 J 가 가장 작은 shard 수 K 가 달라집니다.
- 독립변수: K ∈ {2, 4, 5, 6, 10} (N=20 이므로 크기 10, 5, 4, 3~4, 2), L = 1~10, 규칙 {합치지 않음, 최소 3명 미만이면 가장 작은 다른 shard 와 합쳐 처음부터 학습, 최소 2명 판}.
- 통제: 모든 K 가 같은 채널 표본과 같은 삭제 순서를 씁니다. 배정은 무작위 순열 방식입니다.
- 측정:
  - CPU: 채널 300가지 × 삭제 순서 20가지. 누적 에너지, 누적 UL 사용량, 누적 로컬 학습 호출, 최소 인원 미달 확률, 합치기 횟수.
  - J = 0.5 × (누적 통신 / 단일 모델 재학습의 누적 통신) + 0.5 × (누적 계산 / 단일 모델 재학습의 누적 계산). 이전 SISA 실험의 K 선택 점수와 같은 형태입니다.
  - GPU: K ∈ {2, 4, 5, 10} × L ∈ {0, 3, 6, 10} × {합치지 않음, 합침} 의 최종 앙상블 정확도.
- 판정: 합치기(최소 3명) 규칙에서, 처음부터 최소 인원을 만족하는 K 만 대상으로 합니다. eps* 기준 조건의 절반 이상에서 L=1 의 최적 K 와 L=10 의 최적 K 가 다르면 지지합니다. 에너지가 정의되지 않으면 UL 사용량으로 판정합니다.

### E4 — ④ 삭제 중 대역 몰아주기

- 가설:
  - H4a(구현·수식 검증): 심볼당 전력 상한이면 대역 b 배에 삭제 UL 지연이 1/b 가 됩니다.
  - H4b: client 총 전력이 제한되어도, eps* 기준 반복 규칙에서 b=4 일 때 UL 지연 감소가 2배 이상 남습니다.
  - H4c: 총 전력 상한에서 1회 전송으로 대역을 4배 넓히면(잡음 4배), 삭제 후 정확도 손실이 1pp 이하입니다.
- 독립변수: b ∈ {1, 2, 4} (K=4 블록 중), 전력 제약 {심볼당, 총 전력}, 명목 SNR {0, 10, 20 dB}, eps {eps*, 1e-4}.
- 측정:
  - CPU: 채널 1,000가지 × 20명 삭제 평균. UL 지연, UL+DL 지연, 에너지, 평균 최대 반복 수, 다른 shard 의 감속 배수.
  - GPU: seed 5개 × 잡음 {0.01, 1} × b × {1회 전송, eps* 반복} × 삭제 4건(shard 마다 1명).
- 다른 shard 가 계속 학습하는 경우에는 남은 K−b 블록을 나눠 써야 하므로 (K−1)/(K−b) 배 느려집니다. 학습이 끝난 뒤의 삭제라면 이 비용은 없습니다.

### E5 — ⑤ guard 대역과 누설

- 가설:
  - H5a: CFO 로 인한 shard 사이 누설이, 삭제 후 다른 shard 에 삭제 대상의 영향을 학습 난수 변동보다 크게 남깁니다.
  - H5b: guard 를 넓히면(0 → 2 → 8 부반송파) 그 영향이 단조 감소합니다.
- 물리 모형: SISO OFDM 64 부반송파, shard 당 9개, 한 심볼에 update 좌표 9개. client 별 잔여 CFO e×U[-1,1] (고정). 블록 중심 공통 위상은 보상합니다. 주파수 평탄 채널을 송신 전에 역보상합니다. client i(shard j) 의 신호가 shard g 수신기에 들어오는 계수는 (h_min,j / (n_g h_min,g))·Re(L_i[g 부반송파, j 부반송파]) 입니다.
- 독립변수: CFO 범위 e ∈ {0, 0.01, 0.05}, 배치 {붙임 guard 0 / 2 / 8, 교차 배치}.
- 음성 대조: e=0, 그리고 shard 사이 항만 0 으로 만든 oracle.
- 삭제 대상: 백도어 client 0 (자기 표본의 80% 에 3×3 트리거, label 0).
- 측정:
  - (a) 교차 누설 에너지 비
  - (b) 삭제하지 않은 shard 의 source 와 reference(삭제 대상 없이 처음부터 학습) 사이 예측 불일치·파라미터 상대 차이
  - (c) SISA 삭제 후 앙상블 트리거 성공률(ASR) − reference ASR, 백도어 shard 의 삭제 전·후 ASR
  - (d) guard 에 쓴 부반송파 비율
  - 기준값: 같은 reference 를 다른 난수 tape 로 학습했을 때의 차이
- 판정:
  - 음성 대조는 파라미터 상대 차이 1e-3 미만, 예측 불일치 0.1% 이하여야 합니다. 배치 크기에 따른 부동소수 오차가 학습 중 커질 수 있으므로 0 이 아니라 이 수준으로 봅니다.
  - H5a 는 가장 영향이 큰 조건의 (b) 또는 (c) 가 기준값보다 클 때 지지합니다.
  - H5b 는 e=0.05 에서 guard 0→2→8 로 (b) 의 파라미터 차이가 단조 감소한 seed 가 80% 이상일 때 지지합니다.

## 5. 결과 해석 규칙

- G0 가 `all_passed` 이면 실제 잡음 한계는 10,000 보다 큽니다. 이 설정에서는 무선 잡음이 학습을 거의 방해하지 않는다는 뜻이고, 무선 쪽 기여는 에너지와 지연으로만 주장할 수 있습니다.
- H1a 와 H1c 가 함께 지지되면, 채널 고정 구간 배정은 정확도 손실 없이 "배정 절차까지 포함한 정확 언러닝"을 만족합니다. 이는 채널 기준 배정을 주장하는 근거가 됩니다.
- H2a 와 H2b 가 함께 지지되면, 채널 순서 참여는 정확도 손실 없이 비용을 줄입니다.
- H3 가 미지지이면 shard 크기는 단일 삭제 기준으로 정해도 충분하다는 결론입니다.
- H4b 가 미지지이면 대역 몰아주기는 전력 제약 때문에 지연 이득이 없습니다. H4c 가 지지되면 1회 전송으로 잡음을 감수하는 편이 낫습니다.
- H5a 가 미지지이면 "누설은 측정되지만 언러닝 결과에는 학습 난수 이하의 영향"입니다. 이 경우 guard 를 아키텍처 요소로 주장하기 어렵습니다.

## 6. 한계

- 시뮬레이션입니다. 완전 CSI, 완전 동기, 합성 채널을 쓰고 실제 RF 측정이 아닙니다.
- 데이터셋 하나, 작은 CNN, 160 라운드, seed 5개입니다. 통계적 일반화를 주장하지 않습니다.
- 정확성 검증은 같은 난수 tape 에서의 일치입니다. 분포 수준의 정확 언러닝 증명이 아닙니다.
- 배치(vmap) 계산이라 배치 구성에 따라 부동소수 오차가 생길 수 있습니다. 일치 확인은 허용 오차로 판단하고 값을 함께 보고합니다.
- 비용은 정규화 단위입니다. 실제 지연(ms), 에너지(J), 회로 전력은 측정하지 않습니다.
