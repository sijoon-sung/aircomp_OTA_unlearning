- **H1a 고정 구간·해시는 소속 변화 0, 나머지는 >0: 지지** — 위 (a) 표
- **H1b 소속 변화가 난수 변동보다 큰 예측 차이를 만든다: 미지지** — SISA-ref 불일치가 난수 기준보다 큰 경우 비율 0.200 (기준 0.8), 평균 비 0.579
- **H1c 고정 구간의 정확도 손실 1pp 이하(순위 자르기 대비): 지지** — 정확도 채널 순위 돌려 담기 0.6915, ID 해시 무작위 0.6909, 채널 순위로 정렬 후 자르기 0.6923, 무작위 순열 후 자르기 0.6934, 채널 고정 구간 0.6922
- stable 규칙에서 SISA 와 reference 의 파라미터 최대 차이: 0.064 (배치 크기에 따른 부동소수 오차 수준이면 같은 계산으로 본다)
