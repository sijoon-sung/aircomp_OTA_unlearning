# 라운드 단위 AirComp-SISA 시뮬레이션: 문제 상황 확인과 배정 트레이드오프

이 폴더는 AirComp 연합학습에서 SISA 구조로 정확 언러닝을 할 때 생기는 문제가 **실제로 있는지**(P0), 그리고 shard 배정에서 학습 비용과 삭제 비용의 **트레이드오프가 실제로 나타나는지**(P1)를 라운드 단위 시뮬레이션으로 확인합니다.

이전 폴더(`sisa_arch_20261006`)의 실험은 무선 부분을 "잡음 분산을 식으로 계산해 더하는" 방식이었습니다. 이 폴더는 매 라운드, 매 shard마다 **송신 전력 계산 → 심볼 송신 → 채널 가산 → 수신 복조 → 장부 기록**이 실제로 실행됩니다. 로컬 학습은 이전과 같은 실제 SGD입니다(`sisa_arch` 의 `LocalTrainer`, `common` 을 가져다 씁니다).

## 1. 무엇을 확인하는가

### P0-A 코드 분리 다중 shard AirComp 의 간섭과 언러닝 흔적 (`exp_p0a_cdma.py`, `cdma.py`)
기존 다중 그룹 AirComp처럼 shard들이 **같은 자원에 동시에** 보내고, 각 shard는 자기 코드를 붙이며, 서버는 합을 받아 코드로 shard 합을 분리합니다. 전력 정렬은 shard 안에서 합니다. 해결책을 붙이지 않은 이 일반적인 설정에서 shard 간 간섭이 얼마나 생기고, 그 간섭이 삭제 대상의 흔적을 다른 shard에 얼마나 남기는지 잽니다.

- 송신: shard k의 client i는 심볼을 L칩으로 펼쳐 b_i·x_i·c_k[l] 을 보냄 (b_i = 1/(n_k|h_i|α_k), 칩당 전력 ≤ P).
- 칩 타이밍 오차: client마다 δ_i ~ U[0, 상한], 지연된 코드 (1−δ)c[l] + δ c[l−1].
- 채널: 모든 shard의 칩 신호가 하나로 더해지고 칩마다 잡음 N(0, σ²)이 실제로 생성됨.
- 수신: shard k는 c_k로 역확산 후 α_k를 곱함. 결과 = 자기 shard 성분 + 다른 shard에서 샌 성분(간섭) + 잡음. 세 성분의 에너지를 매 라운드 기록.
- 설정: walsh(L=4, 칩 오차 0/0.1/0.3), PN(L=16, 64, 칩 오차 0; L=16 칩 오차 0.1) × SNR 0/20dB × 삭제 대상(최약·중간 채널).
- 흔적: 삭제하지 않은 shard 모델의 "u 있던 원래 학습" vs "u 없이 같은 코드 시스템으로 처음부터 학습" 예측 불일치. 칩 잡음은 두 경우가 같고(짝 비교), 기준인 난수 변동만 다른 잡음·배치를 씀.

### P0 자원과 노출 (`exp_p0_problem.py`)
| 항목 | 질문 | 어떻게 재는가 |
|---|---|---|
| (b) 자원과 삭제 비용 | SISA를 얹으면 평상시 자원이 K배가 되고 삭제 통신량은 줄지 않는가 | K=1,2,4,5,10 의 학습·삭제 장부(심볼, 에너지, 계산, 시간). 디지털 전송 기준선 장부 포함. 빈 블록 재사용 시 삭제 시간 |
| (c) 노출 | 서버가 받은 (잡음 섞인) shard 집계에서 개인 정보가 shard 크기에 따라 얼마나 드러나는가 | 실제 송수신을 거친 집계와 member update의 cosine, 집계로 member의 주 label 추정 적중률. SNR 무잡음/20dB/0dB |

### P1 배정 트레이드오프
배정 규칙 9가지(무작위, 채널 정렬 자르기, 채널 돌려 담기, 채널 고정 구간, ID 해시, 학습 최적 λ=0, λ=0.5, λ=2, T+1% 내 U 최소) × 전송 규칙 2가지(최대 전력, 전력 낮춤)에서, 학습 비용 T와 삭제 비용 U(채널 순위 0/25/50/75/100% 위치 5명 각각 삭제, 평균)를 실제 장부로 잽니다. T가 늘 때 U가 주는 파레토 전선이 있는지, λ=0 대비 손익분기 삭제 수, 정확도를 보고합니다.

## 2. 무선 모델 (`aircomp_sim/radio.py`)

- 실수 기저대역 등가, 위상은 송신 전에 보상. client i 는 s_i = x_i / (n·|h_i|·α) 를 보내고, 서버는 y = Σ|h_i| s_i + z (z ~ N(0, σ²)) 를 받아 α·y = (1/n)Σx_i + α z 를 얻습니다.
- 전력 정렬: α ≥ C/(n·min|h_i|·√(PD)) (가장 약한 client가 상한 P에 닿음). 1회 집계 오차 MSE₁ = D α² σ².
- 전송 규칙: `maxpow` 는 α를 최소로 두고 MSE₁ > eps 면 R = ⌈MSE₁/eps⌉ 번 반복, `minen` 은 MSE₁ ≤ eps 면 α를 키워(전력을 낮춰) MSE = eps 로 맞춤. eps 기본값 10 (G0 측정).
- 무선 제어 공유: `align='shared'` 는 모든 shard가 전체 최약 채널 기준 공통 α, `sched=('shared', q)` 는 전체 채널의 하위 q 분위수 미만 client가 송신하지 않음.
- 장부: UL 심볼 수(반복 포함), 정규화 시간(빈 블록 b개 재사용 시 1/b), DL 비트, 송신 에너지(실제 ‖s_i‖²·R), 반복 수, 송신 횟수, 계산 호출, 달성 집계 오차, 전력 상한 비(≤1 검증).
- 디지털 기준선: client마다 직교 자원으로 32 bit × D 를 Shannon 용량 log₂(1+P|h|²/σ²) 로 보낼 때의 사용량과 에너지.

단위 검증: 무잡음에서 복원 오차 0, 전력 상한 비 1.000, 측정 잡음 분산이 예측값과 일치(`radio.py` 식 참조).

## 3. 실행

```bash
git clone -b research/sisa-arch-experiments-20261006 https://github.com/sijoon-sung/aircomp_OTA_unlearning.git
cd aircomp_OTA_unlearning/aircomp_sim_20261007
pip install torch torchvision numpy --index-url https://download.pytorch.org/whl/cu121   # GPU 판
python run.py --quick        # 동작 확인 (수 분)
python run.py                # 전체 (FashionMNIST 자동 다운로드, seed 5, 160라운드)
```

## 4. 결과를 읽는 법

- **P0-A** 표에서 walsh·칩 오차 0 은 완전 직교라 간섭 0 입니다. 칩 오차나 PN 코드에서 "간섭/자기 신호"가 0보다 크면 shard가 섞이고, 그때 "미삭제 shard 불일치"가 0보다 크면 데이터 격리만으로는 삭제 대상의 흔적이 다른 shard에 남는다는 뜻입니다. "간섭/잡음"이 작으면 간섭이 채널 잡음에 묻혀 흔적이 작습니다. 크기는 "난수 변동" 열과 비교합니다.
- **P0-(b)** 표에서 학습 UL 심볼이 K에 비례해 늘고 삭제 UL 심볼이 K와 무관하면, "자원 K배, 삭제 통신 불변"이 확인된 것입니다. 삭제 계산과 (최대 전력에서의) 에너지는 줄어야 합니다. 디지털 열과 비교하면 AirComp가 남기는 이점의 크기가 나옵니다.
- **P0-(c)** 표에서 n이 작아질수록 member 적중이 오르고 비member 적중은 낮게 유지되면, 노출이 개인 정보임이 확인됩니다. SNR이 낮을수록 적중이 떨어지면 채널 잡음이 노출을 가리는 효과입니다.
- **P1** 표의 파레토 전선에 배정이 2개 이상이면 트레이드오프가 존재합니다. 손익분기 삭제 수가 작을수록 언러닝 고려 배정이 빨리 회수됩니다. 전력 낮춤 모드에서는 크기가 같은 배정의 에너지가 같으므로 전선이 생기지 않는 것이 정상입니다(수식 예측).
